## 【任选课回忆】
### 此模块用于帮助选课困难的同学，声明：仅对当年选修课程有效。课程大纲有可能修改，因此在你看到的这一年的课程难度可能与笔者当年有偏差。
1、【Linux编程】： 大三上、2学分、开卷考试
- 建议想要熟悉Linux系统的同学修读
- 期末考试会涉及C语言编程题，主要是文件操作
- 知识点多，需要花时间提前在书上整理勾画

2、【Java程序设计】：大三上、2学分、期末大作业
- 适合喜欢学习编程语言的同学选修，认真学完黑马程序员的视频，完成期末大作业难度并不大。
- 大作业内容是使用Java语言开发一个程序并撰写报告，报告类似于实习周的软件设计报告，但要求字数更多。
- 笔者的程序是在黑马程序员的Java拼图游戏的基础上添加了一些功能：如导入自己的图片，程序自动完成3x3切割；用户可以自己切换是3x3、4x4还是5x5模式。

3、【计算机图形学（全英文）】：大三上、2学分、期末大作业
- 建议编程能力不强的同学慎选！！！难度很大，课程跨度也很大
- 老师是按照OpenGL的教程进行授课的，一学期只讲完了基础内容的章节。但是期末大作业是按照学号分配的题目，总共三道题目。
- 题目主要涉及环境光遮蔽、阴影算法等的实现，难度高。

4、【计算机通信与网络】：大三上、3.5学分、开卷考试
- 推荐学习，是408专业课之一，跟住老师或者王道考研学习即可。学进去之后会有豁然开朗的感觉。
- 教课的老师虽然年龄较大，但人很亲切，会认真回复你的问题。
- 期末复习跟住老师发的资料及慕课上的模拟卷，基本都是类似的问题。
